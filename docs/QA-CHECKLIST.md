# QA checklist — v0.7.0-alpha

## Instalación

- [ ] El ZIP instala y activa sin errores fatales.
- [ ] WordPress reconoce la versión `0.7.0-alpha`.
- [ ] El tema funciona con WooCommerce inactivo.

## Catálogo

- [ ] Grid en 4, 3, 2 y 1 columnas según viewport.
- [ ] Categoría, stock, precio y CTA son legibles.
- [ ] Add-to-cart AJAX actualiza el contador del header.
- [ ] Ordenamiento y paginación funcionan.

## Producto individual

- [ ] Producto simple disponible y agotado.
- [ ] Producto variable exige selección antes de comprar.
- [ ] Galería, thumbnails, zoom y lightbox.
- [ ] Tabs de descripción, información y reseñas.
- [ ] Productos relacionados.
- [ ] Barra móvil acciona el formulario correcto.
- [ ] Navegación por teclado y foco visible.

## Responsive

- [ ] 360 px, 768 px, 1024 px y 1440 px.
- [ ] Sin scroll horizontal.
- [ ] Safe-area inferior en dispositivos compatibles.
- [ ] `prefers-reduced-motion` respetado.

## Personalizador visual

- [ ] Cada color global actualiza su token sin CSS inválido.
- [ ] La paleta WooCommerce modifica acciones, precios, ofertas, estados y tarjetas.
- [ ] Las cuatro formas de botón se aplican a controles globales y WooCommerce.
- [ ] Las variantes de carrito y búsqueda conservan etiqueta accesible.
- [ ] Los cuatro contornos de icono funcionan en cabecera, widgets y formularios.
