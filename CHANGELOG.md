# Changelog

Los cambios relevantes del proyecto se documentan en este archivo siguiendo el formato de Keep a Changelog.

## [0.6.0-alpha] - 2026-08-05

### Agregado

- Nuevo diseño completo de Product Cards.
- Shop Archive con hero, breadcrumb, toolbar, filtros y empty state nativo.
- Grid responsive de 3/2/1 columnas.
- Header profesional con barra informativa, búsqueda especializada, cuenta y carrito dinámico.
- Navegación móvil accesible y panel lateral de filtros.
- Footer con menú y áreas de widgets.
- Soporte visual para producto, galería, carrito, checkout, avisos y Mi cuenta.
- Arquitectura CSS modular con tokens de diseño.
- Opciones de Customizer para anuncio y color de acento.
- Templates estándar de WordPress y soporte de editor.

### Cambiado

- Evolución de la base publicada `0.1.0` a `0.6.0-alpha` para el Sprint 2.
- Integración WooCommerce basada en hooks y overrides mínimos.
- Documentación técnica, instalación y estructura del repositorio.

## [0.1.0] - 2026-08-05

### Agregado

- Skeleton arquitectónico inicial del tema para el Sprint 1.
