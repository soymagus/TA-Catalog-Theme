# Changelog

## 0.7.0-alpha — 2026-08-05

- Sprint 2 consolidado: nuevas tarjetas, archivo de tienda y grid responsive.
- Sprint 3: experiencia completa de producto individual.
- Galería y variaciones con capacidades nativas de WooCommerce.
- Barra de compra móvil y mensajes comerciales configurables.
- CSS separado en módulos de tienda, tarjetas y producto individual.
- Documentación y controles de versión actualizados.
- Integración del template catch-all sin duplicar los wrappers gestionados por WooCommerce.
- Colores globales y de WooCommerce configurables desde el Personalizador.
- Formas de botones e iconos de carrito y búsqueda configurables.

## 0.1.0 — 2026-08-05

- Skeleton inicial del tema.
- Templates base de WordPress.
- Diseño responsive inicial y navegación accesible.
- Integración WooCommerce mediante soporte, hooks y wrapper.
- Opciones básicas del Customizer.
- Configuración global mediante `theme.json`.
